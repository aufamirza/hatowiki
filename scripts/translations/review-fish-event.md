# Review terjemahan: ikan event

27 ikan di section event halaman daftar https://www.heartodex.com/en/fish (diperiksa 2026-09-28): Echo of Ancients 5, Call of Whales 7, Modular Streets 5, Dreamlight Cinematics 5, Winter frost season 5.
Kolom **Asli** disalin apa adanya dari halaman detail (`descriptionOriginal`), termasuk salah ketiknya. Kolom **Terjemahan**
mengikuti maksud asli; nama, nama lokasi, dan istilah game tetap bahasa Inggris.

- Kata mencurigakan (pola "y" → "g") ditandai otomatis oleh `scripts/heartodex-sync.mjs`, lalu dicek manual di kolom Catatan
  (termasuk salah ketik yang lolos dari skrip).
- Status event di sumber ("Active Event", "Unavailable — Event ended") tidak disimpan dan tidak ditampilkan.
- Halaman detail event juga punya deret "Event Tokens" per bintang; tidak diminta untuk wildlife, jadi tidak disimpan.
- Empat ikan Frostspore punya dua lokasi di sumber (Old Sea + [EVENT] Frostspore Fish). Ikan Base Game tetap memakai
  satu `location` + `locationZone`; ikan dengan beberapa lokasi memakai `locations` (satu zona per lokasi, seperti serangga).
- Harga jual semuanya bilangan bulat di sumber (tidak ada desimal). Golden Garfish tidak punya harga di sumber → `null` + TODO
  (tampil "—").
